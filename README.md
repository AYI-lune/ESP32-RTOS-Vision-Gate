# 🚦 ESP32 双核 RTOS 云端协同视觉道闸系统

## 📌 项目简介
本项目是一个基于 ESP32 的边缘视觉与云端 AI 协同的道闸控制系统。为应对 OV7670 无 FIFO 缓冲的严苛时序，以及网络通信的高延迟，本项目深度应用了 **FreeRTOS** 的双核架构进行任务调度。

## 🧠 核心技术亮点
1. **双核任务分配**：
   - **Core 1**：运行 `Task_Camera` 高优先级任务，专门负责 OV7670 底层时钟同步（PCLK/VSYNC）与高频图像采集。
   - **Core 0**：运行 `Task_Network` 低优先级任务，负责 WiFi 网络连接、HTTP 数据发送及解析云端返回的 JSON。
2. **队列（Queue）跨核通信**：
   - 通过 `xQueueSend` 与 `xQueueReceive` 实现图像缓冲区的跨核安全传递，避免数据竞争。
3. **硬件-云端协同架构**：
   - ESP32 作为边缘节点采集图像，通过 HTTP POST 发送至 PC 端 Python Flask 服务器（模拟云端算力），获取识别结果后驱动舵机执行开闸，形成完整的物理闭环。

## ⚙️ 技术栈
`C/C++` `ESP32` `FreeRTOS` `OV7670` `HTTP` `SG90`
